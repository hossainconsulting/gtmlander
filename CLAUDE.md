# Claude project guidance

Read README.md and ARCHITECTURE.md before changing anything.

- Commands: `npm run dev`, `npm run build`, `npm run type-check`, `npm run lint`, `npm test`.
- Keep the prototype's status accurate: deployment does not mean planned services are complete. Never invent conversion numbers, clients or results.
- Save dated evidence under `evidence/YYYY-MM-DD/task-name/` for substantive work, following the existing layout.
- Inspect Git status first; commit only task-related changes; never force-push.
